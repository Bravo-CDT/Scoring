Logos and icons for the scoreboard's network diagram, copied in as plain SVG
files rather than pulled in as packages. `index.ts` maps services and
operating systems to them.

- Colour logos (apache, postgresql, docker, wordpress, windows11, debian,
  centos, rockylinux, fedora): Devicon 2.17, MIT,
  https://github.com/devicons/devicon
- linux, nginx, xmpp, ubuntu (filled Ubuntu orange): Simple Icons 16, CC0,
  https://github.com/simple-icons/simple-icons
- Everything else (generic outline icons): Tabler Icons 3.49, MIT,
  https://github.com/tabler/tabler-icons

The brand logos are trademarks of their owners and are used only to identify
the service.
